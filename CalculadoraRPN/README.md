1. Descargar cambios del repositorio remoto (`git pull`)

Antes de comenzar a trabajar o de subir nuevos cambios, **siempre** debes traer la última versión del código para evitar conflictos.

Ejecuta el comando pull:

Bash
"git pull origin <nombre-de-tu-rama>" (Solo estamos en Main entonces con el "git pull" funciona)

2. Guardar cambios y subir cambios

"git add ."
"git commit -m "Nombredelguardado""
"git push"
